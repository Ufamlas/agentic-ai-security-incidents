# Contributing

New records require:
1. at least one source with a stable URL;
2. explicit event and disclosure dates where known;
3. separation of confirmed facts from unresolved claims;
4. independent incident normalization (do not split one causal episode into many incidents);
5. no reproduction of secrets, credentials, exploit payloads, personal data, or unnecessary sensitive details;
6. reviewer sign-off before promotion into `confirmed`.

Use an issue/PR titled `[CASE] short descriptive name`.
