# AASIC Incident Explorer

Open `dashboard/index.html` in a browser to explore the corpus locally.

The dashboard is generated from the canonical JSON records and supports filtering by:
- record class;
- provider;
- confirmed harm;
- actor attribution;
- free-text search over ID, title, provider, agent, summary and tags.

`incidents.js` is a generated browser representation of the canonical `data/AASIC-*.json` records.

## GitHub Pages

For a public web view, this directory can be published with GitHub Pages or copied into a Pages source directory. The dashboard uses no external dependencies or remote APIs.
