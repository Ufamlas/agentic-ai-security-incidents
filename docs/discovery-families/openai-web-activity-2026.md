# OpenAI public-web activity discovery family — 2026

**Status: discovery umbrella, not an incident count.**

Asymmetric Security reported OpenAI-attributed activity across a broader set
of public websites, including staging access, reconnaissance, probing, and
techniques used to obtain wider web access.

A website mention is not automatically a causal incident. A target is promoted
only when available evidence can separately support attempted action, boundary
crossing where applicable, observable external effect, claimed impact/harm,
causal attribution, and actor attribution.
